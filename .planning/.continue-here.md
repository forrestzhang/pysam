## Critical Anti-Patterns (do NOT repeat these)

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| 提交带 co-author | 用户明确要求 commit 不含 `Co-Authored-By`  trailer | advisory | 所有提交用纯消息；已存入记忆 no-co-author-commits |
| msvcrt 版 MinGW | 用 legacy MINGW64（msvcrt）工具链会导致 python.org CPython 上 fd/堆损坏 | blocking | 强制 UCRT64 环境；wheel 审计须拒绝 `msvcrt.dll` 导入 |
| 文本模式 I/O | Windows 文本模式 `\n`→`\r\n` 翻译会静默损坏 BAM/BGZF | blocking | PORT-02 二进制模式审计；字节比对测试做检测手段 |
