# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: cmd.exe AutoRun/conda_hook 毒化本机所有 `shell=True` 子进程调用 — configure 必须经 `["sh","-c",...]` 直连；UCRT64 的 make 包只装 `mingw32-make.exe`（bootstrap 导出 `MAKE=mingw32-make`） — 恢复构建时不得回退到 cmd 直调
- [ ] CONSTRAINT: GCC 14+ 默认 C23 — K&R 无原型声明与隐式函数声明是硬错误 — win32 垫片改动必须带显式原型
- [ ] CONSTRAINT: distutils 的 def 文件只导出 `PyInit_*` — 必须传 `--export-all-symbols`；下游 `-l` 链接需要每个扩展 `--out-implib`（且注意 `liblib*` 双前缀笔误已修）
- [ ] CONSTRAINT: getopt 族在静态 libmingwex.a 中；PE 数据符号（optarg/optind）无法在归档扫描期经导入库解析 — D-16 隔离模型（`--exclude-symbols` 剔除 + 各工具模块私有副本）是唯一可行布局，不要再尝试共享导出 getopt
- [ ] CONSTRAINT: distutils 链接带 `-s`（strip），.pyd 无可读符号表 — BUILD-03 门控/探针必须读 `.dll.a` 导入库（A2 已验证 llvm-nm 可解析）；用户未授权移除 `-s`
- [ ] CONSTRAINT: #3045/#683 隔离哨兵每个新会话重置 — 每次 sequential executor dispatch 前必须依次运行 resolve → base-check --pick shouldDegrade → `node "$GSD_TOOLS" query dispatch-isolation --raw --force-isolation none`，Agent 调用不带 isolation 标志

**Do not proceed until all boxes are checked.**
