## Directory Purposes

**`pysam/` (package):**

- Purpose: all shipped code — Cython bindings, Python facade, C shims
- Contains: `libc<feature>.pyx/.pxd/.pyi` trios, pure-Python modules, C helper sources
- Key files: `pysam/__init__.py`, `pysam/libchtslib.pyx`, `pysam/libcutils.pyx`, `pysam/utils.py`

**`htslib/`:**

- Purpose: vendored upstream htslib (never hand-edit; refresh via `devtools/import.py`)
- Contains: full upstream source + autotools
- Key files: `htslib/htslib/*.h` (public API), `htslib/Makefile`, `htslib/configure`

**`samtools/`, `bcftools/`:**

- Purpose: vendored upstreams with generated `*.pysam.c` patched copies alongside originals
- Contains: `foo.c` (upstream original) and `foo.c.pysam.c` (redirected-stdio build copy) for every C file; both are compiled only via the `.pysam.c` copies
- Key files: `samtools/samtools.pysam.h`, `samtools/bamtk.c.pysam.c`, `bcftools/main.c.pysam.c`

**`import/`:**

- Purpose: templates consumed by `devtools/import.py` to generate the `*.pysam.h/.pysam.c` shims
- Contains: only `pysam.h` and `pysam.c`
- Generated: No (these are the sources)

**`win32/`:**

- Purpose: MSVC compatibility headers; wired into the build only when `platform.system() == 'Windows'` (`setup.py:634-639`), which adds `-Iwin32` and compiles `win32/getopt.c` into every extension
- Status: marked "untested" in `setup.py`; no CI job builds Windows

**`devtools/`:**

- Purpose: vendoring and CI helper scripts; not shipped

**`tests/`:**

- Purpose: pytest suite (run via `pytest tests` with `-s -v` per `setup.cfg`); includes Cython compile smoke tests (`tests/_compile_test.pyx`, `tests/linking_test.py`)

**`linker_tests/`:**

- Purpose: legacy link-strategy experiments; not part of the build

**`doc/`:**

- Purpose: Sphinx docs; `doc/conf.py` version paths are rewritten by `devtools/import.py`

## Key File Locations

**Entry Points:**

- `setup.py`: build entry; defines `cy_build_ext`, 12 `CyExtension` modules (list at `setup.py:699-755`), `clean_ext` command
- `pyproject.toml`: PEP 517 shim → `setuptools.build_meta:__legacy__`; requires `Cython>=3,<4`
- `pysam/__init__.py`: import-time entry; import order matters (chtslib first)
- `devtools/import.py`: upstream vendoring entry (`python devtools/import.py <pkg> <srcdir>`)

**Configuration:**

- `setup.py`: master build config — `HTSLIB_MODE` env var selects htslib linking strategy (`setup.py:475`); `HTSLIB_CONFIGURE_OPTIONS`, `HTSLIB_LIBRARY_DIR`, `HTSLIB_INCLUDE_DIR` env vars
- `setup.cfg`: pytest (`-s -v`, testpaths `pysam tests`), flake8 (max-line-length 120)
- `pyproject.toml`: `[tool.cibuildwheel]` hooks run `make -C htslib distclean` before build
- `htslib/config.h`, `samtools/config.h`, `bcftools/config.h`: generated by configure or written as empty stubs by `setup.py:622-630`
- `htslib/config_vars.h`, `samtools/samtools_config_vars.h`: generated by `write_configvars_header` (`setup.py:199`)
- `pysam/config.py`: generated by `setup.py:598`; exposes `HTSLIB`, `HAVE_LIBCURL`, `HAVE_MMAP`, etc.

**Core Logic:**

- `pysam/libchtslib.pyx`: htslib C-API bindings (748 lines)
- `pysam/libcbcf.pyx`: largest module (5174 lines, VariantFile/VariantRecord)
- `pysam/libcutils.pyx`: `_pysam_dispatch` (line 303), string/encoding helpers, `parse_region`
- `pysam/libcalignmentfile.pyx` (2952), `libcalignedsegment.pyx` (3539), `libctabix.pyx` (1184), `libcfaidx.pyx` (710)

**Build-critical C shims:**

- `pysam/htslib_util.c`, `pysam/htslib_util.h`: helpers linked into libchtslib
- `pysam/dynamic_libs.c` + `pysam/dynamic_curl.h` + `pysam/dynamic_openssl.h`: runtime dlopen of libcurl/libcrypto; only compiled when `CIBUILDWHEEL` is set on Linux (`setup.py:559-563`)
- `pysam/conftest_cstd.c`: C99 feature probe compiled by `cy_build_ext.c99_compile_args`

**Testing:**

- `tests/`: ~25 `*_test.py` files + `conftest.py` + `TestUtils.py`
- `tests/linking_test.py`, `tests/compile_test.py`: verify extension linking/compilation
- Data: `tests/pysam_data/`, `tests/tabix_data/`, `tests/cbcf_data/`

## Naming Conventions

**Files:**

- Cython modules: `libc<feature>.{pyx,pxd,pyi}` — e.g. `libcalignmentfile.pyx`. The `libc` prefix distinguishes compiled modules from pure-Python `pysam/samtools.py`, `pysam/bcftools.py`, `pysam/utils.py`.
- Patched vendored C: `<name>.c.pysam.c` (generated; never edit by hand — regenerate via `devtools/import.py`)
- Generated shim headers: `<pkg>.pysam.h` (e.g. `samtools/samtools.pysam.h`)

**Directories:**

- Lowercase, matching upstream project names: `htslib/`, `samtools/`, `bcftools/`
- Test data dirs snake-cased with `_data` suffix: `pysam_data/`, `tabix_data/`, `cbcf_data/`

**Python symbols:**

- Cython modules expose `__all__` lists aggregated by `pysam/__init__.py:35-49`
- Dispatcher callables in `pysam/samtools.py`/`pysam/bcftools.py` named exactly after the CLI subcommand (`sort`, `mpileup`, `view`, …)

**C symbols:**

- Every exported symbol in vendored code carries a `<pkg>_` prefix (e.g. `samtools_dispatch`, `bcftools_set_stdout`) via `import/pysam.h` renames — required by the cross-extension symbol-collision check

## Where to Add New Code

**New htslib binding (Python-facing feature):**

- Implementation: `pysam/libc<feature>.pyx` + declarations `pysam/libc<feature>.pxd` + stubs `pysam/libc<feature>.pyi`
- Registration: add a `dict(...)` entry to the `modules` list in `setup.py:699-755`
- Re-export: add star import + `__all__` aggregation in `pysam/__init__.py`
- Tests: `tests/<Feature>_test.py`; data under `tests/pysam_data/`

**New vendored upstream file (samtools/bcftools):**

- Do NOT edit `*.pysam.c` directly; add/adjust rewrite rules in `devtools/import.py` (`EXCLUDE`, `SPECIFIC_SUBSTITUTIONS`) and re-run the importer
- Check symbol collisions after build (`setup.py:320` does this automatically on POSIX)

**Windows-specific C compatibility:**

- Shims go in `win32/` (e.g. extend `win32/unistd.h`)
- Build wiring in `setup.py:634-639` (the `platform.system() == 'Windows'` branch)
- POSIX cimports in `.pyx` files (`posix.unistd`, `posix.fcntl`) need `cdef extern` alternatives or platform `DEF` gates — current blockers: `pysam/libchtslib.pyx:10`, `pysam/libctabix.pyx:62-63`, `pysam/libcutils.pyx:22-23`, plus `/dev/null` literal in `pysam/libcutils.pyx`

**New dispatch subcommand:**

- Add a `PysamDispatcher('<collection>', '<cmd>')` line + `__all__` entry in `pysam/samtools.py` or `pysam/bcftools.py`; update `MAP_STDOUT_OPTIONS` in `pysam/libcutils.pyx` if the command needs explicit `-o` handling
