<objective>
Vendor the four C dependencies the MSVC cl.exe pass must compile from source (BUILD-02): zlib (BGZF hard dependency), bzip2 + xz/liblzma (CRAM codec parity with the UCRT64 1027-green baseline — research Q1/A2 adopted: vendor both), and a POSIX regex implementation (hts_expr.c/sam.c unconditional regex.h include — research Q2/A3 adopted: musl-derived, MIT, single-file class). Adopting research recommendations over alternatives with rationale: musl regex over TRE (permissive single-file license, POSIX ERE semantics; TRE is the documented fallback if filter tests disagree in plan 03-05); full bz2+lzma vendoring over disable-in-config (SC-2 suite parity is the safest reading of "完整测试套件全绿").

Purpose: MSYS2's headers are GCC-configured (its zconf.h includes unistd.h — verified) and MSYS2 import libs don't cross toolchains; a self-contained MSVC closure requires in-tree sources (also the Phase-4 self-contained-wheel constraint).
Output: committed vendor/ trees + provenance manifest + a reusable cl compile probe proving MSVC-cleanliness before the build integration plan touches them.
</objective>
